# Araç Kiralama Sistemi

C ile yazılmış konsol tabanlı araç kiralama uygulaması.

## Özellikler
- Araç ekleme, silme, güncelleme, arama, listeleme
- Müşteri ekleme, silme, arama, listeleme (TC kimlik doğrulamalı)
- Araç kiralama, teslim alma, kiralama geçmişi

## Derleme ve çalıştırma
    gcc -Wall -Wextra -pedantic -o arac arac_kiralama.c
    ./arac
